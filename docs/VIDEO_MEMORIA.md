# Guion de vídeo memoria (5-7 minutos)

## 1) Presentación del proyecto (30-45s)
- Nombre: Biblioteca Digital.
- Objetivo: alquiler online de libros usando React, CSS (BEM) y datos mock.

## 2) Arquitectura Front-end (1 min)
- Mostrar estructura: `components/`, `pages/`, `hooks/`, `context/`, `data/`.
- Explicar enfoque de componentes funcionales (10+).

## 3) Requisitos técnicos (2 min)
- React + JSX en páginas y componentes.
- Hooks `useState` y `useEffect` (ejemplos en login, búsquedas y carga de libros).
- Custom hook: `useRentals` y `useAlert`.
- React Router: rutas `/`, `/login`, `/books`, `/my-rentals`, `/admin`.

## 4) Demo funcional (2 min)
1. Login como usuario.
2. Búsqueda por título/autor/ISBN/categoría/idioma/sinopsis.
3. Alquiler de libro.
4. Extensión de alquiler.
5. Devolución.
6. Login como admin y acceso a panel administrativo.

## 5) Diseño e interfaz (45s)
- Estilos modernos: gradientes, tarjetas, jerarquía visual.
- Iconografía con Font Awesome.
- Alertas atractivas con Bootstrap (`alert`).
- Convención BEM en CSS.

## 6) Cierre (20s)
- Limitaciones actuales: sin backend real.
- Próximos pasos: API real, persistencia en servidor, tests E2E.
